HOI4 Mil Ratio Calculator

Set your total military factories, then split them across categories. Each category can be switched on/off with its checkbox, and uses one of three ways to claim mils: a fixed amount (comes off the top first), a % of whatever's left after fixed categories, or a ratio share of whatever's left after that — e.g. ratio values of 1, 2 and 3 on three categories split that remainder 16% / 33% / 50%. Ratio mode is the one to reach for if you'll be flipping categories on and off, since the remaining active ones just re-normalize automatically. Each category is also either Simple equipment (one item gets the whole category) or Multiple equipment ratio (several items split the category's mils by quantity needed × IC cost, so every item gets built in the ratio you actually need). Pick equipment from the Air/Ground categorized dropdown, or fall back to Custom for anything not listed — the toggle locks once a category has equipment in it, so switching domains mid-setup can't scramble your picks. Each item also has a Boost % override — use it when losses of one equipment type are running ahead of the rest, so that item temporarily gets a bigger cut of the category's mils (at the expense of the others in the same template). Navy is ignored.

Save downloads a small .json file with everything on this page — keep it in your project folder next to the .html file. Load lets you pick that file back up. Send both files to a friend and Load works the same way for them.

Experimental: screenshot reading is unreliable and can misread or mislabel items. It always creates an editable category — check every row against the screenshot before trusting it.

Screenshot just the Equipment Cost box if you can — the whole window sometimes works, but with Base Stats / Combat Stats sitting right next to it at the same height, the text reader can occasionally blend the columns together into nonsense. A tighter crop reads far more reliably. Then just paste it (Ctrl+V) anywhere on this page — or use the button if you'd rather pick a saved file. First use each session needs to load a small local text-reading library — everything after that runs offline. Always double-check the numbers it finds.
